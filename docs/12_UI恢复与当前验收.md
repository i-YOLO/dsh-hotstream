# alpha.3 阅读恢复与当前验收

执行日期：2026-10-04；官方 macOS DeepSeek Harness 0.2.0-rc.2，内置 Node 24.18.1，Home `~/.dsh`。本记录是当前修复的真实执行结果，不代替完整 UI 移植和正式发布验收。

## 故障及修复

用户打开真实 BootLoops 新闻后，热点区域变成空白。Host 仍运行、没有活跃模型调用；实际正文的 `<br>` 被渲染器附加了 React 子节点，触发 void-element 异常并卸载页面。已修复 `br` / `hr` 渲染，增加保留侧栏的页面错误边界。实际文章已重新打开，正文与图片正常显示。

图片使用官方 Host / Attachment 自动加载，接近视口时预取，最多两个并行请求；无需逐张点击加载。离开文章会取消读取，缓存命中仍校验 Publication 与文章修订。

走查同时修复了跨 CSS Module 容器名称不一致导致的窄窗排版失效，以及报告页内锚点被误当作导航地址的问题。后台已具有明确的“返回阅读”。收藏不再触发前台整页加载，列表后台更新重新校验已加载内容并保留折叠和位置。
