# alpha.7 模型榜空行修复

日期：2026-10-05。状态：已安装 `0.1.0-alpha.7`，完成原生切页的数据与可访问性回读验证。

## 根因与边界

模型榜与 Tibo 监控共用 `optional` 状态。导航改变页面时没有清除旧模块的数据，在新请求返回前，监控事件被按模型解析成无名称、位次 0 的行，且共享 `undefined` 行标识。重复标识会使旧行在 React 更新后残留。正式综合榜 80 条模型记录的名称和位次均有效；截图中的 7 条空行不在数据库里。

跨页面导航现在同步清除 `optional` 和 `uiMonitor`，新页面等待自己的数据；原有请求代次校验继续拒绝迟到结果。同页后台刷新保留当前有效列表，避免重新引入闪烁。榜单渲染前再验证模型标识、名称与正整数位次，并去除重复标识。合法零分、未知分数和免费价格仍保留。

本次仅修复 Client，不修改正式榜单、价格、模型分数、来源配置或新闻处理规则。
