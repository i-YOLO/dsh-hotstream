## 验收发现与修复

暂停状态下无效唤醒和 foreground loading 导致频闪；现在准入与下一次唤醒共用规则，空闲 SQL 不推进数据版本，watch 刷新保持静默。正文列表不再传长正文，详情通过许可检查返回；HTML 使用白名单 React 节点，图片显式读取并检查地址、字节和格式。分类榜现在独立分页，筛选在完整排名上执行。

每次 attempt 请求/响应/usage/审计单独保存；调用列表分页返回摘要，原始内容只在展开时读取。存储失败时停止准入，官方 Session 中已落盘的响应可回放。行业/提示词、归组候选、参数与实际图片引用冻结；源编辑、关系/输入变化、人工修订和旧综述投影均通过事务/版本控制。

账单确认不授权重试；protected unknown 在清空后仍可人工核对，旧 epoch 不能重试。设置和来源命令可重放而不重复投影。External 请求在失败后仍不得同身份变更内容。取消后的响应保留证据，业务不会继续提交。

## 保留门禁与结果限制

真实三条新闻平均分 60 / 60 / 58 均未达到 T2=76，未进入精选；这是先前 23 次调用阶段的结果；随后全批真实测试已有 35 条达到默认门槛进入精选。首次导入不产生当前热度和实时报告；后续明确完成历史补编 16 日报、7 周报、3 月报，10 次真实导读调用均落盘结算，有内容报告通过正式 Gateway 回读，覆盖不足单独标注，见 `11_真实报告验收.md`。真实综述中“没有公司回应”的推断未通过证据核对，阅读改用来源摘要；原输出保留，不宣称全部模型质量通过。

Windows x64 未执行，真实 X/公众号/其他收费服务未得到本轮授权，均只做模拟协议检查。操作系统实际休眠、全盘写满，以及 10 万条库下的完整聊天 UI 压力仍需要独立环境/执行记录；SQLite 页限满盘、只读、响应保存失败与迟到提交已做故障注入。维护者和反馈地址未提供，正式发布前必须用真实信息补齐。

代码实现、自动/模拟验证、真实模型样本、原生 UI 与正式发布是不同结论。尚未执行的项目保留为门禁；候选包不能代替所有 57 项或两平台的正式认证。
