# Windows x64 官方桌面验收流程

当前没有 Windows 环境，以下流程未执行，正式发布门禁保留。

1. 使用官方 Desktop 0.2.0-rc.2 x64，记录版本、提交与内置 Node；隔离 DSH_HOME 与 Electron user-data，不使用生产 Home。
2. 首次启动后退出，从插件管理器或官方 CLI 安装同一个 alpha.2 tgz，核对 SHA-256。记录依赖/peer 检查、Client factory、Remote 与 Worker/WASM 解析结果。
3. 未初始化时打开、切页并重启，确认业务采集/模型/计算计数为 0。初始化仅使用模拟模型和网络；保存并展示完整阅读、许可正文/图片、日报/周报/月报、主题、收藏与后台。
4. 用实际 Gateway 执行严格 payload、watch 基线/取消/重连、命令 CAS/重放、账单确认与讨论预填。草稿和附件不得覆盖，发送计数必须为 0。
5. 默认关闭两个可选模块，记录采集/模型/计算为 0；用明确标注的模拟数据验证模型榜和监控，再做关闭、取消、迟到提交及重新开启。
6. 执行隐藏、正常退出、强杀、重启、升级、卸载重装与十轮启停。每轮记录 Worker、timer、订阅、请求及审计 writer 数量，核对数据/收藏/配置和模型授权计数保留。
7. 使用目标内置 Node 执行自动回归、存储/网络故障注入和 10 万条性能测试；保留 Windows 路径、锁文件、中文短词、WASM 和聊天 UI 压力结果。
8. 在 `specs/acceptance-executed.json` 逐项追加 Windows 的环境、结果与日志/截图，不批量修改原始 `acceptance.json`。任何不匹配、未执行或失败仍保留门禁。

测试服务均模拟。真实收费模型或第三方采集须另外得到有模型、次数和费用范围的授权；本轮 macOS 的 30 次授权不能默认为 Windows 新额度。
