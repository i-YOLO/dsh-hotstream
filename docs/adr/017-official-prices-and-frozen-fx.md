# ADR 017：完整官方价格与榜单汇率快照

日期：2026-10-05。保持 AIHOT `cc66cceb` 的官方价格来源与 DSH 原生运行边界。

## 问题

迁移只复制了 2026-09-30 的 34 条补充价格，漏掉 2026-09-26 的 53 条基础价格。已有模型库又跳过初始化播种，后续新增数据无法回填。榜单没有写入 USD/CNY 汇率，已有美元报价也无法在人民币列显示。

## 决策

- 保留所有按日期命名的上游价格文件；构建时排序合并，较新文件覆盖较早观察，共 87 个型号。生成兼容的 JSON 和 Host 内嵌数据，并保留逐型号核验日期。
- 每次榜单刷新在模型归一后导入价格，即使模型库已经存在也会补齐。按规范 slug 解析实际 model_id；同币种只更新来源为 official-seed 且日期不晚于新观察的记录，手工记录优先保留。SQLite 的价格主键包含币种；跨币种记录保留，读取优先手工来源和较新的观察。
- 已启用的模型榜采集／计算独立于新闻处理开关，不派发新闻模型；暂停的新闻与常规 Tibo 仍保持暂停。
- 使用已有的、受生命周期管理的 PublicNetwork 请求上游同一 Frankfurter/欧洲央行免费接口。不使用模型或付费凭据，不改系统网络，不扩大 Arena 代理范围。
- 校验 USD 基准、正数汇率和有效日期；失败、无效响应或旧日期保留最近有效报价，没有历史报价则保持空。模块诊断记录失败原因。
- 把汇率、观察日期、来源写入新榜单的 summary.fx，旧榜单保持原快照。价格及汇率不进入评分或排名算法。
- 页面区分待核验、待换算、未披露该项价格、无官方付费 API 和免费；展示汇率日期与来源，详情保留原币金额和价格核验日期。

## 验证

见 `docs/14_模型价格修复验收.md`。正式库只通过插件公开命令和自身 Worker 写入；SQL 查询用于只读验收。沿用既有 DSH Remote，不引入私有宿主接口或宿主数据库访问。
