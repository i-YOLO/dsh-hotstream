# 管理命令、阅读材料和账单边界

保持固定 DSH / Cordis 版本和原生组合包架构。迁移 001–012 使用已确认的连续编号与原 checksum；未知、缺号或 checksum 冲突在新 SQL、诊断表和 WAL 改动前拒绝。没有删库重建或覆写旧配置的修复路径。

设置、来源、事件、报告、偏好与账单确认采用显式范围、commandId 和修订检查。设置更新只影响新任务；行业版本在内容改变时递增，已应用分析记录实际行业/配置版本。来源更新与相关投影在单个业务事务中执行。重复命令不再次改写版本或重建投影。External 请求身份在失败和取消后仍保持原内容，不通过重新入队覆盖。

unknown 的人工账单确认独立于重试授权；确认后的 attempt 不自动释放，旧 epoch 的待核对证据仍可读取和确认，但不能重试。30 分钟等待和最多一次自动释放仍用于未经人工确认的 unknown。每个真实模型测试 allowance 固定路由、文章范围和累计上限，重启/清空/预算窗口均不重置。

模型响应先存入 SQLite。若该写入失败，尝试把同一原始响应通过官方辅助 Session writer 落盘；恢复扫描核对持久请求身份后回放，不派发模型。全盘写满可能同时阻止两种存储，此时保留发送控制证据、暂停准入并诊断，不能声称响应仍已持久。SQLite full/read-only/I/O 错误暂停工作；关闭先撤销租约与信号，再排空回执、审计和网络，最后释放 storage。

列表与事件摘要不传输长正文；许可详情才读取正文、翻译与媒体。Client 将 HTML 转换成白名单 React 节点，不注入源 HTML。图片仅在用户点击后由 Host 重新核对 Publication、修订和媒体地址，执行每跳/Socket 公网检查、2 MiB 限制及图片格式校验，使用官方 Attachment 保存，再返回本机 data URL。许可或导航变化拒绝迟到结果；阅读不派发模型。

新闻修改、重评和拆分移走材料时撤销旧事件综述投影，历史输出保留。真实测试中出现了缺乏来源依据的“公司没有回应”推断，阅读投影回退到已保存来源摘要；该校验有明确适用范围，不能称为通用事实核验器。

可选模型榜保留 v17 尺度、入选、预算与原排序。读取器最多两个并发，一次有限补试，随后按固定名录次序写入快照；失败保留最后成功证据。分类与开发者/开放权重筛选发生在完整排名分页前，不重新编号。监控每帖读取更新后的上下文，公告不等于完成，故障/恢复链接与人工修订持久记录。
