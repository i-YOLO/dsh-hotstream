# ADR 014：后台显式保存与受限接入测试

日期：2026-10-05。目标保持 DSH Desktop `0.2.0-rc.2`、Cordis `4.0.4` 和锁定 AIHOT `cc66cceb`。

## 决策

后台继续运行在原生 Slot，采用共享 React、DSH Button / Input / Menu / Switch / Modal 和已有主题变量。以 AIHOT AdminPage 的 1320px 内容宽度、卡片、标题和表格层次统一七个管理页面。Button 显式指定 primary，避免目标版本默认 ghost 导致保存入口弱化。

设置与信源各自维护本地草稿，通过一次明确保存提交；后台变更不覆盖草稿。设置以配置 revision 防止丢失更新，写入后回读一致才清理 dirty。导航统一拦截为保存并离开、放弃修改、继续编辑，保存失败保留输入。

凭据只通过 DSH Credentials 的 `credentialKey('hotstream', service)` 写入。读取只返回 configured，保存成功清空密码输入。SocialData 变更要求周期监控已暂停，清除或更换会推进模块 generation 并取消旧任务；凭据保存不唤醒、重试或启用监控。付费响应中回显的认证值在持久化前脱敏。

单次 Tibo 测试是独立持久任务 `monitor-test`：一页搜索、全任务最多两次上下文、最多五次识别、maxAttempts=1，命令幂等并受当前服务预算限制。Host、存储 writer、generation / epoch / lease 共同拒绝失效写入。测试不推进周期游标、不消费历史 backlog、不启用周期监控。样本没有重置事件仍保留真实识别结果；没有完整历史证据时近 90 天次数显示未知。

模型榜手动刷新只用公开来源。系统 DNS 是本轮实测可达的插件选项，不改变系统设置；公共 DoH 保留并报告解析超时。每次请求保留地址校验，IPv4/IPv6 自动选择避免只尝试不可达地址。所有来源失败让任务失败，部分成功保留逐源状态与有效榜单；校准、覆盖率、证据图和成榜门槛维持上游规则。

## 验证

自动化覆盖与原生、真实来源验证分开记录，见 `docs/13_后台与接入验收.md`。用户录入自己的 Key 后才进行授权范围内的实际请求；持续运行成本和 Windows 不属于本轮已验证范围。
