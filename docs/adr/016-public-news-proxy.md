# ADR 016：公开新闻代理及失败 RSS 恢复

日期：2026-10-05。目标保持 DSH 0.2.0-rc.2 / Cordis 4.0.4；沿用 ADR 015 已核对的目标版本代理、公共抓取和资源所有权契约。

## 实证

Google Research、Hugging Face Blog、Import AI 和 Mistral AI 的 RSS 直连均连接超时；使用现有本机 HTTP 代理均返回 HTTP 200（约 0.5–1.1 秒）。此前的 Arena 专用代理只覆盖榜单读取，并未覆盖新闻 RSS。用户明确要求修复这些新闻源。

## 决策

增加 `network.publicProxyUrl`，默认 null，旧配置由 schema 补默认值。后台“预算与网络”提供“公开新闻 HTTP 代理”输入，保存后生效。只允许不含凭据、路径或查询参数的 HTTP(S) 代理 origin；不修改系统代理、系统 DNS 或 DSH 全局 dispatcher。

RSS / 公开列表、文章提取、公开图片理解素材和许可正文图片使用公开读取路径。仅 GET / HEAD、无请求体、无凭据头及认证查询参数的请求可使用它；其他请求继续原连接路径。SocialData、大家啦、Jina、Embedding 等计费服务仍由原服务通路与统一回执协调器处理，DSH LLM 路由不变。Arena 原有专用代理配置保留。

每个后台任务、预览或图片读取拥有自己的代理连接生命周期，沿用任务取消信号并在完成后 await close。预览加入协调关闭流程；不会遗留由旧配置创建的代理连接。所有重定向、私网目标、受保护头、TLS、响应大小及超时边界保留。

代理变更仅为之前失败的匿名 RSS 取消尚未执行的旧采集任务并安排新的采集身份，冻结新配置。运行中的任务、已有提取 / 模型请求、响应证据和历史游标不改写。在途匿名 RSS 结束后若失败，调度器会识别旧线路重试并用新任务接续，避免保存新线路后仍无限重试旧直连。其余来源继续原间隔，不通过清空或全站手动采集掩盖失败。成功状态只能由真实采集事务提交。

无数据库迁移，不修改历史 checksum、用户模型选择、并发或预算。

## 验证

隔离测试覆盖公开 RSS 路由、付费提供方仍走原通路、认证请求不进入公开代理、旧配置补默认、仅失败 RSS 新建任务及原请求快照保留；私网 / 重定向 / 取消保护复用 ADR 015 的实际代理传输回归。正式桌面读取、提交和来源状态另记于 `docs/15_RSS代理修复验收.md`，不把连通性检查当作业务入库完成。
